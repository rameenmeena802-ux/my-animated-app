# Mission Control Center - User App

Group no 2 - React Project Part 1 & 2

Multi-page React application with React Router and JSONPlaceholder API.

## Live Demo
https://YOUR-ACTUAL-VERCEL-URL.vercel.app

## Features
- User List page - All users from JSONPlaceholder API
- Details page - Individual user details on click
- Loading state - Spinner while data loads
- Error state - Error message if API fails
- Navigation - React Router for multi-page flow
- Responsive design

## Tech Stack
- React.js
- React Router DOM
- Vite
- Axios / Fetch API
- JSONPlaceholder API
- Tailwind CSS / CSS
